# Cybersecurity Log Analyzer

## Project Description
This project is a simple cybersecurity tool created
using Python. It helps identify failed login attempts
and detect possible suspicious activity.

## Project Features
- Counts total login attempts.
- Counts failed login attempts.
- Displays a warning when three or more failed
  login attempts are detected.
- Helps identify possible security threats.

## Technologies Used
- Python
- GitHub
- GitHub Codespaces
- Freshworks

## How to Run the Project
1. Open the project in GitHub Codespaces.
2. Open the terminal.
3. Type: python log_analyzer.py
4. View the security analysis results.

## Branches
- main: Main production branch.
- development: Used for development work.
- feature/log-analysis: Used to develop the
  log analysis feature.

## Purpose
The purpose of this project is to practice
version control, branch management, and issue
tracking using GitHub and Freshworks.
